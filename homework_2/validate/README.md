# Задача 2. Validate

Проверить, возможен ли порядок извлечения `popped` при порядке добавления `pushed`.
По условию значения уникальны, `popped` — перестановка `pushed`, длина — от 1 до 100 000.

[Решение](solution.py) · [Тесты](test_solution.py)

## Алгоритм

`validate_stack_sequences(pushed, popped)` имитирует стек обычным списком Python.
Добавляем очередное число из `pushed`. Пока вершина равна следующему элементу
`popped`, извлекаем её и увеличиваем `pop_index`.

Совпавшую вершину можно извлечь сразу: именно она нужна следующей.
Если вершина не совпадает, остаётся добавлять новые элементы. Когда добавлять
больше нечего, необработанный остаток `popped` означает невозможный порядок.
Ответ — `pop_index == len(popped)`. Входные массивы не меняются.

## Сложность

- Время: `O(n)` — каждый элемент добавляется и извлекается не более одного раза;
  добавление в список Python в среднем по серии операций занимает `O(1)`.
- Память: `O(n)` — в стеке может оказаться вся последовательность.

## Запуск и тесты

Из корня репозитория; первая строка — `pushed`, вторая — `popped`, числа через пробел:

```bash
python3 homework_2/validate/solution.py
python3 -m unittest homework_2.validate.test_solution -v
```

Тесты проверяют оба примера, один элемент, прямой и обратный порядок,
несколько извлечений подряд, невозможный порядок и длину 100 000.
Для всех 873 перестановок длины от 1 до 6 ответ сравнивается с полным перебором
операций. Также проверяются сохранность входов, пустые входы, разные длины и ввод-вывод.
